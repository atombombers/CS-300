•	  What was the problem you were solving in the projects for this course?

I needed to build a program to help advisors at ABCU look up Computer Science course information efficiently. The program had to load course data from a file, store it, sort it, and let advisors to quickly retrieve the course data they needed.

----------------------------------------------------------------------------------------------------------------------------------------
•	How did you approach the problem?

I started by planning my solution out in pseudocode so that I had a guideline for what exactly what needed to happen. I compared vectors, hash tables, and trees to figure out which data structure made the most sense to address the problem. Understanding how they work made it easier to pick the best one for fast lookups and sorting.

----------------------------------------------------------------------------------------------------------------------------------------
•	How did you overcome any roadblocks?

I split the problem into smaller parts and tested as I went. I used print statements to help find bugs. Staying organized made fixing issues less stressful.

----------------------------------------------------------------------------------------------------------------------------------------
•	How has your work on this project expanded your approach?

This project taught me how valuable planning is before beginning any project. Having the knowledge of common data structures and gaining the insight to choose the best one for my program is a new skill I acquired that has helped make me more confident designing bigger programs step by step.

----------------------------------------------------------------------------------------------------------------------------------------
•	How has your work on this project evolved the way you write programs?

Aside from learning and implementing data structures that will better organize my program data in the future, I write clearer, cleaner code now. I make sure my code handles bad input and stays easy to update later.
